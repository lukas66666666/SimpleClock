## Firmware
The firmware is written in C++ using ArduinoIDE.
## Parts list
- 1x Seeed XIAO ESP32C3
- 3x Keyboard Switches
- 3x Keycaps
- 1x 2.25in TFT Screen
- 1x 3.3V Piezo Buzzer
- 4x M3x5x4 Heatset Inserts
- 4x M3x16mm Screws
- 3d printed case
- custom PCB
